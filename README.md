# ISA Hub — Earl Shilton Building Society

A responsive, standalone website focused exclusively on ISAs. No current accounts, no loans, no cross-sell — just Easy Access, Fixed Rate and Junior Cash ISAs in one clear, focused hub.

## What's here

Plain HTML, CSS and vanilla JS — no build step, no dependencies. Open `index.html` in a browser, or serve the folder with any static file server.

```
index.html              Home
easy-access-isa.html    Easy Access ISA product page
fixed-rate-isa.html     Fixed Rate ISAs (1/2/3 year terms)
junior-isa.html         Junior Cash ISA
isa-transfer.html       ISA transfer process
isa-guide.html          Plain-English guide to ISA allowances & rules
calculator.html         Interactive ISA growth calculator
faqs.html                Frequently asked questions
contact.html            Contact form, phone/email, branches
404.html                Not found page
assets/css/styles.css   Shared design system
assets/js/site.js       Nav toggle, dropdown, footer year
assets/js/calculator.js Calculator logic
assets/images/          Favicon / brand mark
```

## Design

Deep navy (`#0c1830`–`#1f3562`) with a warm gold accent (`#d4a017`) and a teal secondary — a trustworthy, mutual-society feel without looking like a generic bank template. Mobile-first, responsive breakpoints at 640px / 900px, system font stack (no external font requests).

## Note

This is a concept/demo build. Rates, branch addresses and contact details throughout are illustrative placeholders, not live data.
